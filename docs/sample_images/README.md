# 평가자용 샘플 이미지

세 이미지는 모두 **가상 데이터**로 만든 화면이다(가상의 "샘플카드", "샘플은행", 가상 영수증). 실제 개인정보는 없다.
`src/`의 HTML을 브라우저로 열어 캡처하면 같은 이미지를 다시 만들 수 있다.

사용법: 서비스 → **📷 캡처·영수증으로 지출 추가**(또는 지출 내역 탭 → 이미지 올리기) → 세 장을 함께 선택 → 확인 표를 본다.
AI 인식 결과는 실행마다 조금 다를 수 있으며, 아래는 2026-11-20 이후 2026년 12월까지 테스트할 때의 기대 결과다.

| 파일 | 확인하는 규칙 | 기대 결과 |
| --- | --- | --- |
| `sample_card.png` | FR-05 목록 인식, **FR-07 일자·요일만 있는 날짜** | 6건(스타벅스 역삼점 4,800 · 배달의민족 23,000 · GS25 선릉역점 3,200 · 카카오T 택시 12,400 · 무신사 59,000 · 교촌치킨 역삼점 21,000). 날짜는 "18일(수)" → **2026-11-18**, "17일(화)" → 2026-11-17, "15일(일)" → 2026-11-15. 각 행에 "화면에 월이 없어 요일이 맞는 가장 가까운 과거 날짜로 정했어요" 안내. 상단 합계 412,600원은 거래로 잡히지 않는다. |
| `sample_bank.png` | FR-06 **돈의 방향**(출금·입금), 잔액 무시 | 5건. 출금 3건(이마트 성수점 45,800 · 쿠팡 27,900 · 월세 이체 450,000)은 **체크됨**. 입금 2건(당근 환불 12,000 · 급여 2,300,000)은 **"들어온 돈" 표시 + 체크 해제**. 날짜는 2026-11-07, 11-05, 11-05, 11-03, 11-03. 잔액 금액은 거래 금액으로 쓰지 않는다. |
