# 실사용자 테스트 진행 안내 (UT_GUIDE)

평가 기준 G5·G7에 맞춰 진행한다. **진행자(팀원)가 이 문서를 보고 그대로 따라 하면 된다.**

## 1. 참여자 조건 (G5)

- **팀원은 참여할 수 없다.**
- 서비스 타깃에 해당하는 사람만 참여한다. 아래 중 하나 이상이어야 하며, 해당 근거를 기록한다.
  - 생활비를 스스로 관리하는 대학생(용돈·아르바이트 수입, 자취 등)
  - 월급을 받기 시작한 사회초년생·초기 직장인
  - 가계부를 써 봤지만 그만둔 경험이 있는 사람
- 다른 팀 교육생도 위 타깃에 해당하면 참여할 수 있다(근거 기록 필수).
- 목표 인원: 6~8명 (최소 5명)

## 2. 개인정보 원칙 (G7)

- **이름·전화번호·이메일은 묻지도 적지도 않는다.** 참여자는 T1, T2 …의 가명으로만 기록한다.
- 설문 폼(Google Forms 등)을 쓸 경우 "이메일 수집"을 끄고, 이름 문항을 만들지 않는다.
- 본인 카드 내역을 올리기 싫어하면 **체험 모드 + 평가용 샘플 이미지**로 진행한다. 본인 내역을 올린 경우에도 그 화면을 캡처해 기록에 남기지 않는다.
- 서비스의 동의 화면을 참여자가 직접 읽고 동의하게 한다.

## 3. 15분 미션

진행자는 참여자에게 아래 순서만 안내하고, 조작은 참여자가 직접 한다. 막히는 지점은 도와주기 전에 메모한다.

| 단계 | 시간 | 참여자가 할 일 | 진행자가 기록할 것 |
| --- | --- | --- | --- |
| ① 접속·동의 | 2분 | https://final-project-frontend-seven-beta.vercel.app 접속 → "로그인 없이 체험하기"(또는 Google 로그인) → 동의 화면 읽고 시작 | 처음 화면에서 무엇을 하는 서비스인지 바로 알았는지 |
| ② 지출 기록 | 4분 | "📷 캡처·영수증으로 지출 추가" → 샘플 이미지 3장(또는 본인 캡처 2장 + 영수증 1장) 업로드 → 확인 표 확인·수정 → 저장 | 업로드 버튼을 찾는 데 걸린 시간, 확인 표에서 고친 항목 수와 이유 |
| ③ 목표 설정 | 2분 | 오른쪽 "목표 세우기" → 추천값 확인 → 저장 | 추천값을 그대로 썼는지, 바꿨다면 왜 |
| ④ AI 코치 | 5분 | 채팅 첫 화면의 소비 알림 카드 버튼 누르기 → 자유 질문 3개 → 답변 아래 "🔎 근거" 펼쳐 보기 → 목표 제안 카드가 뜨면 [적용] 또는 [무시] | 실제로 한 질문, 답이 맞다고 느꼈는지, 근거를 열어 봤는지 |
| ⑤ 설문 | 2분 | 아래 설문 응답 | — |

## 4. 설문 문항

1~5점 문항은 1점(전혀 아니다) ~ 5점(매우 그렇다)이다.

| 번호 | 문항 | 형식 |
| --- | --- | --- |
| Q1 | 다음 중 해당하는 것을 모두 고르세요: 생활비를 관리하는 대학생 / 사회초년생·초기 직장인 / 가계부를 쓰다 그만둔 적 있음 / 해당 없음 | 객관식(복수) — **타깃 근거** |
| Q2 | 캡처·영수증을 올려 지출을 기록하는 게 직접 입력보다 편했다. | 1~5점 |
| Q3 | AI가 읽은 결과(날짜·금액·가맹점)가 정확했다. 틀린 게 있었다면 무엇이었나요? | 1~5점 + 주관식 |
| Q4 | 오른쪽 소비 요약만 보고 이번 달 상황을 바로 파악할 수 있었다. | 1~5점 |
| Q5 | AI 코치의 답변이 내 질문에 맞고 도움이 됐다. | 1~5점 |
| Q6 | 답변 아래 "근거"가 AI 답변을 믿는 데 도움이 됐다. | 1~5점 |
| Q7 | 소비 알림 카드나 목표 제안이 실제로 써 볼 만했다. | 1~5점 |
| Q8 | 가장 불편했던 점 한 가지는? | 주관식 |
| Q9 | 꼭 추가됐으면 하는 기능 한 가지는? | 주관식 |
| Q10 | 이 서비스를 계속 쓸 생각이 있나요? 이유는? | 예/아니요 + 주관식 |

## 5. 끝난 뒤

1. 응답을 [USER_FEEDBACK.md](USER_FEEDBACK.md)의 참여자 표와 응답 원본에 옮긴다(가명만).
2. 팀이 함께 상위 피드백 2~3건을 고르고, 반영할 것과 반영하지 않을 것(이유 포함)을 정한다.
3. 반영한 경우 커밋 메시지에 `UT-T1` 처럼 근거가 된 참여자 가명을 적고, 전후 화면을 캡처한다.
